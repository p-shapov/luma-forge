## Workflow

A ComfyUI workflow definition used to run inference.

In v1, the only supported Workflow is [`t2i Z-Image Turbo`](https://docs.comfy.org/tutorials/image/z-image/z-image-turbo) for text-to-image generation.

In future versions, the system may support more workflow types, such as:

- image-to-image
- image editing
- text-to-video
- video-to-video
- animation
- other workflow types

**Invariants:**

- The workflow is not created or modified by user in v1
