## Workflow Catalog

A local catalog of Workflow Presets available inside the application.

The Workflow Catalog is application-owned metadata. It is stored in the application sources or bundled application metadata.

**Invariants:**

- The Workflow Catalog is read by the local application.
- The Workflow Catalog is not created or modified by the user in v1.
