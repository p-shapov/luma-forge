# Provisioned Remote Lifecycle Refactor Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the current `provisioned_remote_compute` workspace-mutation model with a `provisioned_remote` runtime backed by generic workspace persistence, a durable lifecycle operation journal, and native background lifecycle execution.

**Architecture:** Domain state is split into generic workspace state, provisioned remote runtime snapshots, and generic lifecycle operation envelopes with provisioned remote payloads. SQLite uses one shared database owner, one generic `workspaces` table, and one generic `lifecycle_operations` table; the provisioned remote service owns cross-table invariants and background execution. Tauri commands remain adapters that call services, map domain responses to binding-safe DTOs, and emit typed frontend events.

**Tech Stack:** Rust 2021, Tauri 2, tauri-specta, Specta, sqlx SQLite, Tokio, serde, time, uuid.

---

## Scope Check

This spec touches one subsystem boundary: provisioned remote native lifecycle management. It also requires command contract and generated binding updates because command responses and typed events expose the new lifecycle operation model. Frontend UI redesign is out of scope; only generated bindings should change after command and event contract changes.

#[derive(Debug, Clone)]
pub struct SqliteNativeDatabase {

    pub async fn connect(path: impl AsRef<Path>) -> Result<Self, sqlx::Error> {
        let options = SqliteConnectOptions::new()
            .filename(path)
            .create_if_missing(true);

            .await
            .expect("workspace schema bootstrap should succeed");
        lifecycle_journal::schema::bootstrap(&pool)
            .await
            .expect("lifecycle journal schema bootstrap should succeed");

        Ok(Self { pool })
    }

    pub fn pool(&self) -> SqlitePool {
        self.pool.clone()
    }
}
